# BUILD: DAV FRAOL — EXTROVERTED 3D CREATIVE PORTFOLIO

You are building the flagship personal website for **Dav Fraol**.

This is NOT a conventional portfolio.

This is NOT a corporate website.

This is NOT a simple developer portfolio.

This should feel like an **interactive digital experience** created by a creative technologist, filmmaker, designer, and developer.

The website itself must demonstrate creativity, motion, visual design, 3D interaction, storytelling, and technical ability.

The goal is that someone opens the website and immediately thinks:

**"This is different."**

---

# 01 — THE CREATIVE DIRECTION

The visual identity should be:

**EXTROVERTED**
**BOLD**
**CINEMATIC**
**3D**
**EXPERIMENTAL**
**FUTURISTIC**
**DARK**
**ELECTRIC BLUE**
**PLAYFUL**
**LUXURIOUS**
**UNEXPECTED**

Think:

* digital art installation
* futuristic creative studio
* cinematic title sequence
* interactive film
* experimental design portfolio
* high-end creative developer website
* futuristic personal brand

Do NOT design a standard portfolio.

Do NOT create a hero with:

"Hi, I'm Dav"
"Web Developer"
two buttons
three cards underneath.

That is exactly what we are trying to avoid.

The design must have personality.

# 25 — PERFORMANCE

This website will contain significant 3D and animation.

Performance is extremely important.

Implement:

* lazy loading
* optimized textures
* compressed images
* WebP/AVIF where appropriate
* lazy video loading
* code splitting
* responsive assets
* efficient Three.js scenes
* device capability detection
* reduced effects on low-end devices
* prefers-reduced-motion support

Create graceful fallbacks.

If WebGL is unavailable, the website should still look excellent using 2D/CSS animations.

# 29 — DESIGN QUALITY CONTROL

Before considering the website finished, inspect every section.

Ask:

Does this look like a normal portfolio?

If YES → redesign it.

Does this section look like a template?

If YES → redesign it.

Is the animation unnecessary?

If YES → remove it.

Does the website feel visually connected?

If NO → improve transitions.

Does the 3D actually contribute to the experience?

If NO → change it.

Does the website feel like Dav Fraol's personal brand?

If NO → redesign it.

---

# 30 — MOST IMPORTANT RULE

Do not play safe.

This website is supposed to be **bold and memorable**.

I would rather have:

ONE spectacular interactive section

than

TEN ordinary sections.

The website should feel like someone combined:

**a creative studio**
+
**a cinematic film**
+
**a futuristic digital art installation**
+
**a developer portfolio**

into one experience.

The website itself should be the strongest portfolio piece.

Build it with strong visual direction, not generic UI conventions.

Start by creating the complete experience and then refine every interaction for polish, responsiveness, accessibility, and performance.
